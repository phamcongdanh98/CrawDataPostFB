Khởi Tạo Ứng Dụng (App) Trên Meta For Developers

Bạn cần sử dụng tài khoản Facebook cá nhân đang trực tiếp nắm quyền Quản trị viên (Admin) hoặc Biên tập viên của Fanpage cần thống kê.

1.1
Truy cập Cổng Meta for Developers

Mở trình duyệt và truy cập trang chủ nhà phát triển của Meta:

↗ Mở developers.facebook.com
Nếu là lần đầu truy cập, bấm Bắt đầu (Get Started) -> Xác minh số điện thoại -> Chọn vai trò "Nhà phát triển".
1.2
Tạo ứng dụng mới (Create App)

Ở góc trên bên phải, bấm vào Ứng dụng của tôi (My Apps) -> Bấm nút màu xanh nổi bật Tạo ứng dụng (Create App).

1.3
Chọn loại ứng dụng: "Doanh nghiệp (Business)"

- Nếu thấy danh sách trường hợp: Chọn ô Khác (Other) -> Bấm Tiếp (Next).
- Chọn loại ứng dụng: Doanh nghiệp (Business) (Bắt buộc để hỗ trợ đầy đủ quyền quản lý Fanpage) -> Bấm Tiếp.

1.4
Điền thông tin và xác nhận mật khẩu

- Tên hiển thị ứng dụng: Điền tên bất kỳ (Ví dụ: Thong Ke Fanpage).
⚠️ Tuyệt đối không chứa chữ Facebook, Meta, FB trong tên vì Meta sẽ từ chối.
- Bấm nút Tạo ứng dụng -> Nhập mật khẩu Facebook cá nhân để xác thực danh tính.

Giai đoạn 2 / 5

Lấy Mã Định Danh Fanpage (Page ID)

Mã Page ID là một dãy số nguyên (15 - 16 chữ số) đại diện duy nhất cho Trang Facebook của bạn.

2.1
Cách 1: Xem trực tiếp trong Fanpage (Dễ nhất)

1. Mở trang Fanpage của bạn trên Facebook bằng máy tính.
2. Bấm vào tab Giới thiệu (About).
3. Bấm vào mục Tính minh bạch của Trang (Page Transparency).
4. Bạn sẽ thấy dòng chữ: ID Trang: 1000xxxxxxxxxxx. Hãy copy dãy số này.

2.2
Cách 2: Tra cứu nhanh bằng đường link Fanpage

Nếu Fanpage có link rút gọn dạng chữ (Ví dụ: facebook.com/nhatrangtoday):

↗ Mở trang Lookup-ID.com
Dán link Fanpage vào ô tìm kiếm -> Nhấn nút tra cứu -> Hệ thống trả về Page ID ngay lập tức.
Giai đoạn 3 / 5

Mở Graph API Explorer & Bắt Buộc Cấp 4 Quyền

Đây là bước cốt lõi nhất để đảm bảo bài viết tải về không bị thiếu tương tác.

↗ Mở Công Cụ Graph API Explorer
3.1
Chọn đúng App vừa tạo

Nhìn sang cột bên phải tại mục Meta App: Bấm menu xổ xuống và chọn đúng tên ứng dụng bạn vừa tạo ở Bước 1.

3.2
Bấm "Add a Permission" và thêm đủ 4 quyền sau:

Gõ từng quyền vào ô tìm kiếm hoặc bấm nút copy dưới đây để dán vào:

pages_read_user_content
(QUAN TRỌNG NHẤT: Bắt buộc để đọc Likes, Comments & Reactions của người dùng)
pages_show_list
(Cho phép xem danh sách các Fanpage mà bạn có quyền quản lý)
pages_read_engagement
(Đọc bài viết và các chỉ số tương tác Fanpage)
read_insights
(Đọc số liệu phân tích và thống kê mở rộng)
3.3
Bấm nút "Generate Access Token"

1. Bấm nút màu xanh Generate Access Token.
2. Cửa sổ Facebook hiện lên: Bấm Tiếp tục dưới tên bạn -> Chọn Fanpage của bạn -> Bấm Tiếp tục.
3. Bật tất cả công tắc màu xanh cho các quyền được yêu cầu -> Bấm Xong (Done).

Giai đoạn 4 / 5

Bí Quyết Lấy Page Access Token Vĩnh Viễn (Never Expire)

Mặc định Token vừa tạo là User Token (chỉ dùng được khoảng 1-2 tiếng sẽ hết hạn). Hãy chuyển thành Page Access Token để dùng vĩnh viễn!

4.1
Chuyển sang Tên Fanpage tại ô "User or Page"

Tại giao diện Graph Explorer, nhìn lên ô User or Page (ngay phía trên ô Access Token):
1. Mặc định ô này đang hiển thị tên Facebook cá nhân của bạn.
2. 👉 Bấm vào menu xổ xuống của ô User or Page.
3. Chọn đúng Tên Fanpage của bạn trong danh sách bên dưới mục "Page Access Tokens".

4.2
Sao chép mã Token vĩnh viễn

- Sau khi chọn tên Fanpage, chuỗi ký tự trong ô Access Token sẽ tự động đổi mới (chuỗi bắt đầu bằng EA...).
- Đây chính là Page Access Token vĩnh viễn. Token này gắn liền với quyền quản trị Fanpage và KHÔNG BAO GIỜ HẾT HẠN (Expires: Never).
- Bấm nút Copy bên cạnh ô Access Token để lưu mã này vào bộ nhớ tạm.

Giai đoạn 5 / 5

Dán Vào Web & Kiểm Tra Trực Tiếp

Bước cuối cùng: Đưa Page ID và Token vào ứng dụng để tự động lưu vĩnh viễn vào hệ thống.

5.1
Mở bảng Cài đặt Fanpage & Token

Bấm nút bên dưới để mở ngay cửa sổ cấu hình trên website này:

5.2
Dán thông tin và bấm "Kiểm tra quyền Token"

1. Dán Page ID (từ Bước 2) vào ô ID Fanpage.
2. Dán chuỗi Access Token (từ Bước 4) vào ô Facebook Access Token.
3. Bấm nút 🔍 Kiểm tra quyền Token.
4. Hệ thống sẽ tự động xác thực và hiển thị tích xanh ✅ cho cả 4 quyền cốt lõi.

5.3
Bấm "Lưu cấu hình" & Bắt đầu lấy bài viết

- Nhấn nút Lưu cấu hình. Dữ liệu sẽ được lưu an toàn vào tệp .env trên máy chủ.
- Quay lại màn hình chính, nhấn nút Lấy bài viết mới để hệ thống kéo về toàn bộ bài viết, likes, comments, shares và biểu đồ phân tích!
